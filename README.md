# Hermes 自进化 AI 系统

> 基于钱学森《工程控制论》设计的多Agent自主进化框架，已稳定运行超过10天，完成6+进化周期。

## 核心特性

- 🧠 **自进化引擎**：基于工程控制论的自适应学习，策略推荐准确率91.6%
- 🤖 **军师旅多Agent架构**：5个专业Agent（司令部/参谋部/侦察连/工兵连/通信连）协作
- 🔄 **级联决策**：3层级联决策链（策略→强度→深度），误差自动补偿
- 🎯 **长链推理**：复杂任务自动分解为多个可验证步骤
- 📊 **PID自适应控制**：参数自调优，消除稳态误差
- 🛡️ **鲁棒容错**：重试概率钳制、迟滞带防止决策抖动、Circuit Breaker

## 使用案例

**案例：帮我找一个157升鱼缸的静音水泵**

系统内部流程：
1. **侦察连(Scout)** 搜索水泵信息 → 遇到JS加密/验证码
2. **参谋部(Staff)** 分析无法直接获取，转向Bilibili/论坛
3. **工兵连(Builder)** 整理产品信息，输出对比文档
4. **司令部(Commander)** 汇总结果，标注"价格未验证"
5. **学习引擎** 记录"中国电商平台无法程序化访问"知识
